## 1. Scope

In scope: one OS window, one `wgpu` surface, a clear-colour frame presented at a 60 FPS target cadence, resize / surface-loss / minimise handling, and tests for the pure logic.

Out of scope: glyphs, the 1D cell buffer, shaders, the texture atlas, grid drawing (M2), hit-testing (M2), multiple windows and shared devices (M4), the BrepKIT kernel (M3). No `newell-model` or `newell-ui` dependency.

| Crate | Role (ARCHITECTURE §1) | M1.3 content | Must NOT know about |
|-------|------------------------|--------------|---------------------|

| `newell-app` | Controller + window manager | `run()`, `App` (`ApplicationHandler`), `FramePacer`, window creation, mapping `WindowEvent` → `Renderer` calls | `wgpu` types beyond what `Renderer` returns |

`newell-app` is currently bin-only. Integration tests in `tests/it/` cannot import from a bin, so it gains a lib target (§3.1). The bin stays a thin shim.

crates/newell-app/src/

```rust
// lib.rs
pub fn run() -> Result<(), AppError>;

#[derive(Debug, thiserror::Error)]
pub enum AppError {
    #[error("event loop failed: {0}")]
    EventLoop(#[from] winit::error::EventLoopError),
    #[error("window creation failed: {0}")]
    Window(#[from] winit::error::OsError),
    #[error(transparent)]
    Render(#[from] newell_render::RenderError),
}
```

```rust
// pacing.rs
pub struct FramePacer { interval: Duration, deadline: Instant }

impl FramePacer {
    /// interval = 1 s / target_fps. NonZeroU32 makes division by zero unrepresentable.
    pub fn new(target_fps: NonZeroU32, now: Instant) -> Self; // first deadline = now (first frame due at once)
    pub fn deadline(&self) -> Instant;
    pub fn is_due(&self, now: Instant) -> bool;   // now >= deadline
    /// Called after a frame is rendered at `now`. Advances deadline (see advance()).
    pub fn on_frame(&mut self, now: Instant);
}

/// Smallest `prev + k * interval` (k >= 1) that is strictly greater than `now`.
/// Missed slots are skipped, not replayed, so a stall never produces a burst.
pub fn advance(prev: Instant, now: Instant, interval: Duration) -> Instant;
```

`advance` needs a `Duration`-based computation: `k = (now - prev) / interval + 1` in nanoseconds via `u128`, then `prev + interval * k`. If `now < prev`, return `prev` (so `is_due` fires immediately; document this). Use `saturating_duration_since`, never an unchecked `duration_since`.

```rust
// app.rs
pub(crate) struct App {
    window: Option<Arc<winit::window::Window>>,
    renderer: Option<newell_render::Renderer>,
    pacer: FramePacer,           // created in resumed() with NonZeroU32::new(60)
    error: Option<AppError>,     // fatal errors from callbacks, returned by run()
}
impl winit::application::ApplicationHandler for App { /* see §4 */ }
```

Constants (in `app.rs`): `TARGET_FPS: NonZeroU32 = 60`, title `"Newell"`, initial inner size 1280×800 logical.

Ownership: `App` owns the window and renderer as plain fields. There is no `static`, `OnceLock` or thread-local holding GPU or window state, so a later `HashMap<WindowId, WindowState>` (M4) needs no restructuring of `Renderer`.

```rust
// renderer.rs
pub const CLEAR_COLOR: wgpu::Color; // placeholder dark neutral; theming is not in scope

pub struct Renderer {
    surface: wgpu::Surface<'static>,
    device: wgpu::Device,
    queue: wgpu::Queue,
    config: wgpu::SurfaceConfiguration,
    needs_reconfigure: bool,
    device_errors: std::sync::mpsc::Receiver<String>, // fed by on_uncaptured_error
}

pub enum FrameOutcome { Presented, Skipped }

impl Renderer {
    /// `window` is an owned handle (e.g. Arc<winit::window::Window>), so the surface is 'static.
    /// Uses Instance::create_surface (safe). create_surface_unsafe is forbidden.
    pub fn new(
        window: impl Into<wgpu::SurfaceTarget<'static>>,
        width: u32,
        height: u32,
    ) -> Result<Self, RenderError>;

    /// Stores the new size; reconfigures only if configurable_extent() is Some.
    /// A zero dimension (minimised) is recorded as "no surface" and does not error.
    pub fn resize(&mut self, width: u32, height: u32);

    /// Acquires, clears to CLEAR_COLOR in one render pass with no draws, submits, presents.
    pub fn render(&mut self) -> Result<FrameOutcome, RenderError>;
}
```

```rust
// error.rs
#[derive(Debug, thiserror::Error)]
pub enum RenderError {
    #[error("no compatible GPU adapter: {0}")]         Adapter(#[from] wgpu::RequestAdapterError),
    #[error("surface creation failed: {0}")]           Surface(#[from] wgpu::CreateSurfaceError),
    #[error("device request failed: {0}")]             Device(#[from] wgpu::RequestDeviceError),
    #[error("surface reports no supported format")]    NoSurfaceFormat,
    #[error("out of GPU memory")]                      OutOfMemory,
    #[error("surface acquire failed: {0:?}")]          Acquire(wgpu::SurfaceError),
    #[error("uncaptured GPU error: {0}")]              Uncaptured(String),
}
```

```rust
// surface.rs (pure)
/// Some((w, h)) iff both dimensions are non-zero.
pub fn configurable_extent(width: u32, height: u32) -> Option<(u32, u32)>;

#[derive(Debug)]
pub enum FrameAction { Present, PresentAndReconfigure, Reconfigure, Skip, Fatal(RenderError) }

/// Input is the wgpu 26 acquire result reduced to `Ok(suboptimal)` or `Err(SurfaceError)`.
/// Taking `Result<bool, wgpu::SurfaceError>` rather than the wgpu texture keeps this pure and testable
/// without a GPU, because `SurfaceTexture` owns a live texture.
pub fn classify(acquire: Result<bool, wgpu::SurfaceError>) -> FrameAction;
```

Mapping (the table is the contract). It matches the `wgpu` 26.0.1 source: `Surface::get_current_texture()` returns `Result<SurfaceTexture, SurfaceError>`, `SurfaceTexture` has `suboptimal: bool`, and `SurfaceError` has exactly `Timeout`, `Outdated`, `Lost`, `OutOfMemory`, `Other`.

| Acquire result | Action | Reason |
|----------------|--------|--------|
| `Ok(false)` | Present | normal |
| `Ok(true)` (suboptimal) | PresentAndReconfigure | present this frame, reconfigure next; must not skip |
| `Err(Outdated)`, `Err(Lost)` | Reconfigure | reconfigure, skip this frame |
| `Err(Timeout)` | Skip | nothing to draw to; also how an occluded or hidden surface shows up (wgpu 26 has no `Occluded` variant) |
| `Err(OutOfMemory)` | Fatal(`RenderError::OutOfMemory`) | unrecoverable |
| `Err(Other)` | Fatal(`RenderError::Acquire(Other)`) | generic failure; surfaces the problem instead of hiding it. Challenger may argue for Skip (§8.5) |

GPU validation errors do not come from acquire in wgpu 26. They arrive through `on_uncaptured_error` and are returned by `render()` as `RenderError::Uncaptured`.

## 4. Event loop and surface lifecycle

**Startup.** `run()` builds `EventLoop::new()`, sets `ControlFlow::WaitUntil(deadline)` per frame (never `Poll`, which spins a core), and calls `run_app(&mut App)`. `run()` returns `app.error` if set.

**Redraw model (bootstrap, not final).** M1.3 drives redraws from the 60 FPS deadline in `about_to_wait`, as a minimal bootstrap to validate the loop. This is the one place the plan runs continuously. It is a stopgap. ARCHITECTURE §4.1 remains the target: later milestones move to model-event-driven redraw. Nothing in `Renderer` or `FramePacer` may assume continuous redraw, so they can be reused under the event-driven model.

**`resumed`.** Create the window only if `self.window.is_none()` (macOS and Android can call `resumed` more than once). Build `Renderer::new(window.clone(), w, h)`, create `FramePacer` with 60 FPS, request one redraw. If the renderer already exists, do nothing.

**`window_event`:**

| Event | Action |
|-------|--------|
| `CloseRequested` | `event_loop.exit()`. Single window in M1.3; M4.6 drops per-window state later. |
| `Resized(size)` | `renderer.resize(size.width, size.height)`; `request_redraw()` |
| `ScaleFactorChanged { .. }` | read `window.inner_size()`, call `resize` (covers the case where no `Resized` follows) |
| `RedrawRequested` | `renderer.render()`; on `Err`, store in `app.error`, call `exit()`. Then `pacer.on_frame(Instant::now())` |
| `Occluded`, other | ignored |

**`about_to_wait`.** `let now = Instant::now()`. If `pacer.is_due(now)`, `window.request_redraw()`. Then `set_control_flow(WaitUntil(pacer.deadline()))`.

**Frame pacing.** The 60 FPS cadence comes from the deadline, not from `Poll`. Each frame advances the deadline by a fixed 1/60 s on the grid (`advance`), so timing does not drift and missed slots are skipped. `PresentMode::Fifo` (guaranteed on all targets) prevents tearing and blocks in acquire or present to the display refresh. On a 120 Hz panel the deadline still caps output at 60 FPS.

**Surface loss and resize.**
- Outdated or Lost → reconfigure, skip the frame (§3.2 table).
- Resize to 0×0 (minimise) → no configure, `render()` returns `Skipped`. Restore → `resize` configures again.
- Surface format: the first sRGB format in `capabilities.formats`, else the first format. `alpha_mode`: the first advertised one. `desired_maximum_frame_latency = 2`.
- Device errors: `on_uncaptured_error` forwards to an `mpsc` channel. wgpu's default handler panics, which §5 forbids. `render()` drains the channel and returns `RenderError::Uncaptured`. Device loss is not recovered in M1.3; it exits with an error (§8.4).
- `Suspended`: no-op on desktop. The renderer and window are kept.

**Adapter and device.** `Instance` with `Backends::PRIMARY` (Metal on macOS). `request_adapter` with `compatible_surface`, `PowerPreference::HighPerformance`, `force_fallback_adapter: false`. In wgpu 26 this returns `Result<Adapter, RequestAdapterError>` and is async. The plan uses a hand-written `block_on` (`std::task::Wake` plus `thread::park`, no `unsafe`) in `newell-render`, so no new dependency is needed (§8.2).

**Render pass.** One `begin_render_pass` with `LoadOp::Clear(CLEAR_COLOR)` and `StoreOp::Store`, no pipeline, no draw call. Then `queue.submit`, `frame.present()`. M2.4 adds the single grid draw call here.

**Raw-window-handle compatibility.** Both crates use raw-window-handle 0.6 (`^0.6.2` from wgpu 26, `rwh_06` from winit 0.30). Cargo unifies them to one version, so no bridge is needed. The Executor confirms with `cargo tree -i raw-window-handle` that exactly one 0.6.x resolves. If `Arc<Window>` does not satisfy `Into<wgpu::SurfaceTarget<'static>>` in wgpu 26, the Executor stops and reports. No bridging crate is added.

**Licences and duplicates.** wgpu and winit add transitive crates. `deny.toml` keeps `multiple-versions = "warn"`, so duplicates warn and do not fail. If `cargo deny check` reports a licence outside the current allow-list, stop and ask the human. Do not edit `[licenses].allow` (ARCHITECTURE §6).

**Nothing else.** No crate for logging, timing, async or FPS stats. `pollster` is not used (§8.2).

**`[[bin]]`.** `newell-app/Cargo.toml` needs `[[bin]] name = "newell", path = "src/main.rs"` (from `M1-setup-v2.md` §3.1). Add a `[lib]` section if absent. The lib name is `newell_app`.

**Lockfile.** Run `cargo check --workspace` once to update `Cargo.lock`, then commit it. Use `--locked` for all later checks.

**MSRV.** Both chosen versions are ≤ 1.85. The existing `msrv` CI job must pass with them. If it fails, stop and ask the human. Do not bump `rust-version` on your own.

**ARCHITECTURE conflicts.** None for the chosen dependencies. The continuous 60 FPS redraw is the bootstrap described in §0 and §4, and it does not override §4.1.
