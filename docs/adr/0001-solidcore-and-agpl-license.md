# ADR 0001: Project license and geometry ownership

**Status:** Historical; kernel selection superseded by ADR 0010.

Newell is licensed under AGPL-3.0-or-later. Geometry operations belong in
`newell-kernel`, behind Newell-owned types. Third-party source retains its own
license and attribution. The current production kernel and exact source pin are
specified by ADR 0010.
