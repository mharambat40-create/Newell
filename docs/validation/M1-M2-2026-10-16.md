## Corrections made during validation

explicit Faces branch. `README_UI.md` §16.8 is higher precedence and explicitly
requires `│   ╰╴Faces ...` followed by `│     Dist ...`; the implementation
already followed that rule. The test now checks those exact authoritative
rows. The ASCII reference and production behavior were preserved.

Rustdoc warnings were fixed by linking the actual composition method
`ActionBox::draw_with` and by avoiding a public link to the private
`ActionBoxUi` trait. No warning suppression was added.

The corrected CommandBar reference and implementation eliminate the two
previous popup/mnemonic failures. No tests were removed or ignored to obtain
the passing result.
