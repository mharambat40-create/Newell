# M3 validation — 2026-10-16

## Scope

M3.1–M3.3 introduce the BrepKIT anti-corruption layer, the first perspective
scene and the initial topology-to-mesh picking path.

M3.4–M3.9 add right-button arcball rotation, middle-button pan and
cursor-anchored wheel zoom. Their camera-math tests pass with the renderer's
normal tests; the hardware-dependent renderer tests also pass when explicitly
enabled.

## Automated results

- `cargo fmt --all --check`: pass.
- `cargo clippy --workspace --all-targets --all-features --locked -- -D warnings`: pass.
- `cargo deny check`: pass.
- `cargo test --workspace --all-features --locked`: 684 standard tests pass;
  nine GPU-dependent tests are intentionally ignored by the default command.
- The kernel tests create a BrepKIT box, verify the six preserved face ranges,
  validate all renderer buffers and reject invalid values through
  `NewellKernelError`.
- The scene tests verify finite camera projection, centre-ray face picking and
  pixel-perfect scene placement left of the Action Box.
- The ignored GPU scene test submits the kernel mesh to the depth-tested M3
  pipeline and checks for validation errors on a machine with a GPU.
- Arcball rotation preserves orbit radius without Euler-angle accumulation;
  pan translates eye and pivot by the same world-space vector; zoom respects
  its positive lower bound and mesh-derived upper bound.

## Runtime inspection

The application starts with the unit box construction and scene pipeline
enabled. The available validation capture channel did not reattach to the fresh
bundle after restart, so this report deliberately does not claim a new visual
acceptance screenshot.
