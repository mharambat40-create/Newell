"Sketch Bar"
Active after Sketch setup OK. Workbench uses the popup in Command_Bar.txt.
Tool popups are centered. See README_UI.md section 42.1 for active tools and gestures.
Point, Line and circular Arc tools use magnetic placement (README_UI.md section 42.1).
Hold Ctrl during drawing for free placement.
Escape cancels a gesture, closes a tool or exits Sketch.
See README_UI.md sections 29.2 and 42.
