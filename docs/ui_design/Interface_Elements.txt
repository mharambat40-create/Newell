A minimalist, professional CAD-style 3D user interface, inspired by Plasticity and Fusion 360. At the center, a matte micro-sphere is intersected by three ultra-thin, anti-aliased axes in pastel colors (red, green, blue) that fade into gradients. The composition is completed by three orthogonal planes made of subtle frosted glass—devoid of any internal grid—offering dynamic translucency within a clean, uncluttered environment.

Generate the code for a 3D navigation interface consisting of two elements. The first is a radial gizmo displaying three colored lines (red, green, blue) that extend from the origin and terminate in solid, labeled circles (X, Y, and Z). The opposite directions should be represented by hollow, semi-transparent rings, with absolutely no lines connecting them to the center. The second element is a light-gray navigation cube with softened edges, divided into distinct, clickable segments: faces, edges, and vertices. The primary faces should feature dark, sans-serif text (e.g., Top, Front, Left, etc.). For optimal usability, clicking any segment—whether a face, edge, or vertex—must automatically orient the camera so that it is normal (perpendicular) to that component. The interface should not include any overlaid rotation arrows or a "Home" view icon.
